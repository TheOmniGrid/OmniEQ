# Changelog

All notable changes to OmniEQ. Dates are release dates.

## 1.0.0 — %%RELEASE_DATE%%

First public release.

### Equalizer
- Parametric EQ with unlimited bands and ten filter types; graphic-EQ mode per channel with parametric filters parked, not lost
- Per-channel and per-device configurations; automatic preset switching on output-device change
- Preamp, balance, per-channel delay, automatic clipping guard
- Curve tools (flatten, expand, compress, nudge, shift), undo/redo, A/B compare, Sets 1–4
- Loudness compensation, headphone crossfeed
- Embedded draggable response curve and a full graph window
- Tone-test generator, live dBFS peak meter, Equalizer APO registration status
- VST2 effects and free Equalizer APO commands per channel (VST3 with a VST3-capable engine build)

### OmniSurround
- Headphone surround virtualisation generated by OmniEQ itself; five-tab window with two profile lists and descriptions, source format, stereo/5.1 upmix, speaker positions with a draggable 3D-style layout view, per-position 7.1 test, levels, speaker-group EQs, output routing, crossfeed
- One-click move from an existing HeSuVi installation: 312 profiles and 1 355 headphone-correction curves taken over, settings carried, config switched in place, engine removal offered separately
- Headphone-correction browser applying measured curves as themselves

### Presets & migration
- Preset store with search, rename, per-preset hotkeys, tray picker
- Import from Peace with Peace's own uninstaller and config.txt repair
- AutoEQ file import; AutoEQ database browser (Peace's database)
- Export/import config; back up everything to one file

### Desktop
- Tray icon with live state, global hotkeys, endpoint volume/mute, set as default device, taskbar toggle
- Lite/Expert modes, text scale, Windows light/dark, per-monitor DPI
- English, Deutsch, Español, Français, Română
- Installer (per-user, no admin) and portable zip
